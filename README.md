# FlexDesk

Gym business management app for local gym owners — membership tracking, check-in/attendance, point of sale, inventory, and an analytics dashboard, all in one place.

**Stack:** Flutter (mobile frontend) + Django REST Framework (backend)

## Status

🚧 In development — v1 build in progress.

## v1 Scope

- Owner login (auth)
- Membership management (CRUD + renewal status)
- Check-in / attendance (members + walk-ins)
- Basic POS (renewals, day-passes, products)
- Inventory (stock tracking)
- Analytics dashboard (revenue, attendance, expiring memberships)
